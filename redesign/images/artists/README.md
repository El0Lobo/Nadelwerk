# Artist-Fotos

Fotos für feste Artists und Gasttätowierer hier ablegen.

Empfohlen:

- JPG oder WebP
- Hochformat im Verhältnis 4:5
- mindestens 1200 Pixel breit
- möglichst kleiner als 500 KB

Danach den Pfad in `content.js` eintragen, zum Beispiel:

```js
image: "images/artists/anna-muster.jpg"
```
